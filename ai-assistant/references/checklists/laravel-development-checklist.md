# Laravel Development Checklist

- [ ] Laravel/PHP version verified.
- [ ] Routes, middleware, controllers, requests, policies, models, jobs, migrations checked.
- [ ] Validation and authorization exist at write boundaries.
- [ ] Transactions protect multi-write state changes.
- [ ] Queries avoid N+1 and have needed indexes.
- [ ] Queues/jobs are retry-safe and observable.
- [ ] Tests/static analysis commands identified.
