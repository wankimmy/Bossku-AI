# Expert Cofounder Stack Checklist

Use this before claiming the agent is expert-level across startup/product/engineering/GTM.

## Engineering

- [ ] Laravel: validation, policies, transactions, queues, tests, security, performance.
- [ ] Nuxt: SSR/hybrid rendering, Nitro/server routes, data fetching, hydration, metadata, performance.
- [ ] Docker/VPS: compose topology, reverse proxy, SSL, backups, rollback, firewall, logs, health checks.
- [ ] Databases: MariaDB, MySQL, PostgreSQL, SQLite, MongoDB differences are explicit.
- [ ] Redis: cache invalidation, queues, workers, failed jobs, locks, rate limits, operational checks.
- [ ] Performance: profiling before caching, indexes before Redis, bundle size before CDN assumptions.

## Product/design/security

- [ ] UI/UX: task clarity, mobile responsiveness, accessibility, loading/error/empty states, anti-AI visual audit.
- [ ] Security: OWASP, STRIDE, authz, tenant isolation, secrets, webhook/payment safety, dependency scanning.
- [ ] QA: tests, static analysis, smoke checks, rollback plan.

## Growth/business

- [ ] SEO/GEO: intent map, technical SEO, schema, answer-engine blocks, internal links.
- [ ] Marketing: positioning, content pillars, ICP, funnel stage, CTA, cadence, metrics.
- [ ] Sales: pipeline, lead qualification, outreach, objections, proposal, closing.
- [ ] Cofounder: decision quality, tradeoff, build-vs-buy, metric, de-scope.
