# What is BosskuAI?

BosskuAI is a **lightweight agentic AI orchestration layer** for people who ship software with AI assistants.

It is **not** a framework for building LLM products from scratch (that’s closer to LangChain). It is **not** a hosted multi-agent crew runtime (that’s closer to CrewAI). See [`comparison.md`](comparison.md).

BosskuAI gives you:

- **Orchestrator** — understand, scope, plan
- **Executor** — implement with minimal blast radius
- **Auditor** — quality, security, performance, maintainability
- **Final reviewer** — “are we actually done?”
- **Memory** — durable project knowledge with optional vector retrieval
- **Integrations** — Cursor, Claude Code, Codex, OpenCode via files and rules

Everything is **repo-local** and **practical**: markdown skills, scripts, and an optional Docker MVP (Laravel + Nuxt) you can run yourself.
