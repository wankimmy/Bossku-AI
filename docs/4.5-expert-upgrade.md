# v1.8.2 Expert Cofounder Upgrade

## Goal

Move BosskuAI from a strong workspace layer to a more credible expert cofounder agent for coding, deployment, UI/UX, security, SEO/GEO, marketing, sales, and content operations.

## Main improvements

- Added cofounder decision-quality playbook and checklist.
- Added expert cofounder stack checklist.
- Deepened Laravel, Nuxt, database, VPS Docker, Redis, UI/UX, and SEO/GEO playbooks.
- Added expert benchmark task bank.
- Added `scripts/eval_expert_coverage.py` to validate expert coverage by routing, reference existence, and required terms.
- Strengthened `skill-index.json` routing terms for the full requested stack.

## New quality bar

BosskuAI should not claim expert-level coverage unless the specialist has:

- routing coverage,
- a concrete playbook,
- a checklist or benchmark case,
- verification commands or evidence requirements,
- guardrails against generic AI output.

## Remaining honest limitation

The benchmark is a deterministic repo-quality proxy. It does not replace human review of actual generated answers. The next upgrade should add saved expected-answer rubrics and sample outputs for each benchmark case.
