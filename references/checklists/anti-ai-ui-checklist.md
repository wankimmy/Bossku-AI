# Anti-AI UI Checklist

Use this when reviewing or building UI that must not look like a generic AI-generated SaaS screen.

## Reject by Default

- Purple/blue gradient hero with glowing blobs.
- Glassmorphism cards everywhere.
- Three equal feature cards with vague icons.
- Fake dashboard mockup in the hero.
- Robot, sparkle, wand, orbit, neural-network, or magic icons as the main visual idea.
- Over-empty SaaS spacing that hides weak information architecture.
- Same rounded card rhythm on every section.
- Stock illustrations that could fit any AI tool.
- Perfect symmetry with no product-specific visual detail.

## Prefer

- One strong product-specific visual idea.
- Real screenshots, real CLI output, real repo structure, or believable product states.
- Useful density: enough content to help the user decide.
- Restrained palette with one accent, not a rainbow gradient.
- Typography with personality but clear hierarchy.
- Asymmetric composition where it helps scanning.
- Small details from the product domain: commands, diffs, file trees, audits, logs.
- Clear mobile behavior and real loading/empty/error states.

## BosskuAI Direction

BosskuAI should feel like a developer tool, not a generic AI SaaS:

- repo-first
- local-first
- terminal-friendly
- practical
- sharp
- low-noise

Good references by feel: GitHub README, CLI docs, engineering notebook, lightweight devtool landing page.
Bad direction: glowing AI dashboard, agent marketplace, productivity super-app.

## Review Question

If the logo and name were removed, would this still feel like BosskuAI?
If not, add product-specific visual evidence.
