# Ratchet Loop Checklist

Use this when improving BosskuAI itself or any project workflow.

## Before changing

- [ ] What metric decides whether this is better?
- [ ] What is the baseline value?
- [ ] What command, test, or review step will be repeated?
- [ ] What is the smallest useful change?

## After changing

- [ ] Same check was rerun.
- [ ] Result is recorded.
- [ ] Decision is explicit: keep, revert, or manual review.
- [ ] Tradeoff is written down if the metric worsened but the change is kept.
- [ ] Follow-up is one concrete next step, not a broad wishlist.
