BosskuAI product tour - proposed direction

A readable 16:9 product tour based on the app’s existing emerald and zinc interface. The final video uses captured application screens, not fabricated dashboard art.

Visual system
BOSSKUAI INTERFACE LANGUAGE
Emerald decisions

Zinc-950 canvas, zinc borders, emerald only for active states and decisions. Amber remains reserved for approval risk.

Typeface: Manrope or system UI for maximum UI clarity. Video titles use a bold, wide set with no decorative serif.

MOTION LANGUAGE

Slow camera. Fast evidence.

Cinematic push-in to a relevant panel, micro-zoom to the proof, then a controlled pull-back to restore context.

No rapid cuts, small text, fake metrics, or decorative gradients. Every screen pause lasts long enough to read.

Storyboard - 52 seconds, silent and README-friendly
01

See the control room - 0:00 to 0:06

Wide shot of the actual home dashboard. A smooth zoom settles on the task composer and the visible Plan, Changes, Audit, and Memory tabs.

Plan before editing - 0:06 to 0:15

Approval Required modal takes focus. A careful zoom shows the change decision, then pulls back to the run context.

04

Audit the diff - 0:24 to 0:35

Changes and Audit tabs show the files touched, checks run, and an auditor result. No claim of a clean audit unless the captured data proves it.

05

Carry the context forward - 0:35 to 0:45

Camera moves to Memory and the Pixel Office agent presence. The shot makes persistent context and visible multi-agent work tangible.

06

Close on the workflow - 0:45 to 0:52

Return to the full dashboard with a concise statement: Plan. Audit. Approve. Remember. The final frame holds the real application.
